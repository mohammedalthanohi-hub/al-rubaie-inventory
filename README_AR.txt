مشروع تطبيق جرد الربيعي ماركت - Android

هذا مشروع Android Studio يحتوي ملف HTML الأصلي داخل التطبيق، مع WebView وصلاحية الكاميرا.
لم يتم تضمين APK جاهز؛ يلزم بناء المشروع باستخدام Android Studio أو GitHub Actions.

البناء في GitHub:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub (وليس ملف ZIP نفسه).
2) افتح Actions ثم اختر Build Android APK ثم Run workflow.
3) بعد نجاح البناء افتح نتيجة التشغيل ونزّل Artifact باسم rubaie-inventory-debug-apk.
4) فك ضغط Artifact لتحصل على app-debug.apk وثبّته على أندرويد.

ملاحظة فنية مهمة:
ملف HTML الحالي يعتمد على BarcodeDetector في المتصفح. دعم هذه الواجهة داخل WebView يختلف باختلاف إصدار Android System WebView والجهاز؛ لذلك يجب اختبار الكاميرا فعلياً على الجوال بعد البناء. لا تعتبر صلاحية الكاميرا وحدها ضماناً لعمل قراءة الباركود.
البيانات تُحفظ محلياً عبر localStorage داخل التطبيق. احفظ نسخة احتياطية بانتظام.
