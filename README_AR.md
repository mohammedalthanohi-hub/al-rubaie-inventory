# مشروع تطبيق جرد الربيعي ماركت (Android)

هذه حزمة **مصدر مشروع Android Studio** وليست APK جاهزًا للتثبيت. تتضمن قارئ باركود بالكاميرا باستخدام CameraX وGoogle ML Kit مع نموذج المسح المضمّن، وقاعدة SQLite محلية تعمل دون إنترنت بعد تثبيت التطبيق.

## الوظائف الحالية في النموذج الأولي
- طلب إذن الكاميرا من أندرويد وتشغيل الكاميرا الخلفية.
- قراءة الباركود وعرضه في خانة الباركود.
- تسجيل/تحديث الصنف والمجموعة ورصيد النظام والكمية الفعلية وسعري الشراء والبيع.
- حفظ البيانات محليًا في SQLite.
- تقرير أولي عن عدد الأصناف والزيادة والنقص وقيمة فرق التكلفة.
- مشاركة ملف CSV لفتحه في Excel.

## بناء APK
1. افتح المجلد في Android Studio حديث.
2. انتظر Gradle Sync مع اتصال إنترنت أول مرة لتنزيل مكتبات البناء.
3. من Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4. ثبّت APK على هاتف Android 12 وامنح إذن الكاميرا.

## تنبيهات قبل استخدامه في جرد فعلي
- هذه نسخة أولية تحتاج اختبارًا على الهاتف قبل الاعتماد التجاري.
- لا يوجد حتى الآن استيراد مباشر لقائمة 7000 صنف من Excel ولا إدارة جلسات/مجموعات جرد متقدمة.
- صدّر نسخة CSV احتياطية بانتظام.
- لم يتم بناء APK أو توقيعه في بيئة هذه الحزمة.
